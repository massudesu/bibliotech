# 🚀 Guia Rápido: Como Abrir e Rodar o Projeto

Siga este passo a passo simplificado para iniciar o projeto no seu computador:

### 1. Criar e Ativar o Ambiente Virtual (venv)
No terminal na raiz do projeto (`C:\bibliotech`):

```powershell
python -m venv venv
.\venv\Scripts\Activate
```

### 2. Instalar as Dependências
```powershell
pip install -r bibliotech/requirements.txt
```

### 3. Rodar o Servidor
```powershell
python bibliotech/projeto_bibliotech/manage.py runserver
```

Agora acesse no navegador: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
